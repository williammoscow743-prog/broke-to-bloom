# 💸 Broke to Bloom

> Transform your finances, one transaction at a time.

Broke to Bloom is a modern personal finance management application designed to help individuals take control of their money. The platform enables users to track income and expenses, monitor cash flow, gain AI-powered financial insights, and manage daily finances from a clean and intuitive dashboard.

---

## 📖 Overview

Managing personal finances can be challenging without a centralized system. Broke to Bloom simplifies financial management by providing an intelligent workspace where users can:

- Record income and expenses
- Monitor cash flow
- Track financial health
- Organize upcoming bills
- Receive AI-powered financial insights
- Visualize spending trends
- Stay informed with notifications
- Search data instantly

Whether you're a student, freelancer, entrepreneur, or professional, Broke to Bloom helps you build healthier financial habits.

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/broke-to-bloom.git
```

## Navigate into the project

```bash
cd broke-to-bloom
```

## Install dependencies

```bash
npm install
```

## Run locally

```bash
npm run dev
```
